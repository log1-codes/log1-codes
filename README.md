## What I Am Building

**CoinLink** is a Web3 payment platform for sending Solana (SOL) through shareable links, with no seed phrase setup. It uses AWS KMS for hardware-backed wallet security and an escrow payment flow, with live data from Helius and CoinGecko. Built with Next.js, TypeScript, Solana Web3.js, Prisma, and NextAuth. [Live Demo](https://coinlink-six.vercel.app/) · [GitHub](https://github.com/log1-codes/TipLink)

**Canopy** is a block-based workspace and editor for note-taking and knowledge management, with hierarchical pages and proxy-level API rate limiting. Built with Next.js 15, Tiptap, Prisma, PostgreSQL, and Zustand. [Live Demo](https://canopy-olive.vercel.app/) · [GitHub](https://github.com/log1-codes/canopy)

**Quantum** is a developer analytics dashboard that unifies your coding data from GitHub, LeetCode, Codeforces, CodeChef, and more, with real-time updates over WebSockets. Used by 150+ people. Built with Next.js, Socket.IO, Tailwind CSS, Framer Motion, and NextAuth. [Live Demo](https://quantum-one-lemon.vercel.app/) · [GitHub](https://github.com/log1-codes/quantum)

**Distributed Job Queue** is a production-oriented job queue built with Go, PostgreSQL, Redis, and a worker pool. [GitHub](https://github.com/log1-codes/Distributed-Job-Queue)

**URL Shortener** is a lightweight service built with Go and PostgreSQL that turns a long URL into an 8-character short code and redirects visitors to the original link. [GitHub](https://github.com/log1-codes/url_shortner)

**Email AI Agent** is an AI agent that categorizes and summarizes your emails, pushes the most important tasks into Notion, and marks the email as read. Built with TypeScript. [GitHub](https://github.com/log1-codes/Email-AI-Agent)

**Multi-Blockchain Wallet Generator** is a client-side wallet generator for Ethereum and Solana that manages BIP-39 mnemonic seed phrases from one seed, with zero server exposure. Built with React, TypeScript, ethers.js, and @solana/web3.js. [Live Demo](https://webbasedwalletgenerator.vercel.app/) · [GitHub](https://github.com/log1-codes/multi-blockchain-wallet-generator)

**EduSync** is a virtual classroom platform with video calls (WebRTC), chat, assignments, notices, quizzes, and an integrated chatbot. Built with the MERN stack. [Live Demo](https://edusync-ug2x.onrender.com/) · [GitHub](https://github.com/log1-codes/EduSync)

**Tomato** is a full-stack food delivery app with restaurant browsing, a persistent cart, Stripe checkout, and an admin panel. Built with React, Node.js, Express, and MongoDB. [Live Demo](https://food-delivery-frontend-iiz8.onrender.com/) · [GitHub](https://github.com/log1-codes/Food-delivery)
